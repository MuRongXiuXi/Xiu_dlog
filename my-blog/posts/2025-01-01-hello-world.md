这是我的第一篇文章。整个博客没有数据库、没有后端、没有 npm 依赖，
写完 Markdown 推送到 GitHub，剩下的交给 Actions 和 GitHub Pages。

## 为什么用纯静态

- **零运维**：没有服务器要打补丁，没有插件要升级，也就没有半夜被打醒的运维事件。
- **快**：整站是纯 HTML/CSS/JS，几 KB 到几百 KB，首屏几乎立刻出现。
- **活得久**：Markdown + 一个 300 行的 Python 脚本，十年后照样能跑。
- **免费**：GitHub Pages 托管，自定义域名 + HTTPS 也不要钱。

## 它是怎么工作的

1. 在 `posts/` 里新建一个 `YYYY-MM-DD-slug.md`，开头写一段 front matter。
2. 运行 `python build.py`，生成静态 HTML 到 `public/`。
3. `git push`，GitHub Actions 自动构建并发布到 Pages。

> 日常写作只需要第 1 步和第 3 步，第 2 步在 CI 里自动完成。

## 支持什么

写文章时可以用这些 Markdown 语法：

| 语法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `` `行内代码` `` | `行内代码` |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮== |

代码块带语言标记：

```python
def greet(name: str) -> str:
    return f"你好，{name}！"

print(greet("世界"))
```
